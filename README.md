# 🎬 העורך של עומר — ריל ערוך בעברית, אוטומטית, על המחשב שלך

הפכתי את מערכת העריכה שבניתי לחודשים לסקיל חינמי של Claude Code.
אתה נותן קליפ שבו אתה מדבר למצלמה — מקבל ריל ערוך: כתוביות בסגנון 2026,
הוק חזק, גרפיקות שתומכות במה שאתה אומר, מוזיקה, ומוכן להעלאה.

**הכול רץ אצלך במחשב.** הסרטונים שלך לא עוזבים אותו. אין הרשמה, אין קרדיטים,
אין תשלום.

---

## מה צריך

יש שני מסלולים — הסקיל בוחר לבד לפי מה שמותקן אצלך:

### 🟢 מסלול מהיר (מומלץ להתחלה — 2 דקות התקנה)
חיתוך שתיקות + כתוביות עברית מדויקות + הוק חזק.

| כלי | התקנה |
|---|---|
| [Claude Code](https://claude.com/claude-code) | מנוי Claude (Pro/Max) |
| FFmpeg | יש brew? `brew install ffmpeg`. אין? **אל תדאג — הסקיל יתקין לך לבד** |
| ספריות פייתון | `pip3 install pillow python-bidi faster-whisper` (גם את זה הוא יעשה) |

> **בלי brew?** הסקיל מוריד ffmpeg מוכן ומגדיר אותו בעצמו — אתה לא צריך לעשות כלום.
> בפעם הראשונה יורד גם מודל תמלול עברי (1.2GB). מהפעם השנייה — ישר לעבודה.

### 🔵 מסלול מלא (עוד 3 דקות, ~3GB)
כל מה שלמעלה + גרפיקות מלאות, B-roll, מוזיקה, אפקטים.

| בנוסף | התקנה |
|---|---|
| [Node.js 18+](https://nodejs.org) | הורדה מהאתר |
| ספריות הרנדר | `cd remotion && npm install` |

**אפשר להתחיל במהיר ולשדרג מתי שרוצים.**

## מה הוא עושה בפועל

1. **מתמלל** את הקליפ בעברית עם חותמת זמן לכל מילה
2. **חותך** שקטים ארוכים ומתקן את הזמנים
3. **מתכנן** — קורא את התמלול, מבין מה אתה אומר, ובוחר גרפיקות שתומכות בדיוק
   בטענה של כל רגע (לא קישוט אקראי)
4. **מרנדר** ריל מלא: כתוביות, הוק, סצנות, מוזיקה, ייצוא תקין לאינסטגרם
5. **מתקן** — "תגביה כתוביות", "פחות גרפיקות", "תחליף מוזיקה" — ורנדר מחדש

**זמנים אמיתיים** (נמדד על קליפ של 52 שניות, מקבוק רגיל):

| שלב | מסלול מהיר | מסלול מלא |
|---|---|---|
| תמלול | ~90 שניות | ~90 שניות |
| עריכה ורנדר | **~25 שניות** | 4-8 דקות |
| **סה"כ** | **~2.5 דקות** | ~8 דקות |

## החוקים שבנויים בפנים

הסקיל לא ממציא ולא מקשט. הוא עובד לפי פלייבוק שזיקקתי מניתוח פריים-אחר-פריים
של רילים ויראליים ומעשרות סבבי שיפור על סרטונים אמיתיים:

- **כל סצנה חייבת לתמוך במה שנאמר באותו רגע** — גרפיקה שלא משרתת את המסר נפסלת
- **רק מספרים שנאמרו בפועל** — אפס המצאות
- **3 השניות הראשונות** שייכות להוק ולפנים שלך
- **אלמנט אחד בכל רגע** — הרבה עריכה, אפס בלגן
- **בלי אימוג'ים**, בלי קופסאות סביב טקסט, ניגודיות בכל מצב
