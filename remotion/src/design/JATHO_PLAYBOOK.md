## 1. מנוע הנרטיב (THE NARRATIVE ENGINE)

### 1.1 Hook formulas (verbatim, with the visual that rides them)

| Formula | Verbatim example | Visual at t=0 |
|---|---|---|
| **Negative imperative + numeric promise** | "Never post on Instagram again without turning on these five settings" (DX0MuRvSFV2 [0s]) · "Never, ever, ever post on Instagram without using this brand new feature" (DSh8cgtjfGX [0s]) | Blurred 5-row checklist floating above head (t001); 3D caps caption that RE-STYLES mid-hook white→red-cracked at 1.5s (DSh8cgtjfGX t001→t002) |
| **Shock phrase + authority meme** | "No, no, no, I'm sexually attracted to this new Instagram update" (Dau4zb1SsbG [0s]) | Split-screen: Zuckerberg keynote top / his crying reaction bottom; red glow "NO" stacking word-by-word (t001–t002) |
| **Cheat-code accusation** | "Instagram seriously just gave you the biggest fucking cheat code and you didn't even notice" (DXo0c5bkn53 [0s]) | Gradient title + fake settings row with BLURRED label, toggle flips OFF→ON on the word "cheat code" (t001→t002) |
| **Recency news drop** | "As of last week, Instagram dropped a massive update" (DM5X-WgxK27 [0s]) | Caption slams per phrase; at 3.0s a glowing "SECRET SETTING" toggle flashes with zero explanation (t003) |
| **Claim-first cold open + flashed answer** | "This is how the algorithm works for Instagram stories" (DUDyNkajSDl [0s]) — thesis as the very first words, zero throat-clearing | Topic stamped as a designed chest title; the ENTIRE algorithm flowchart faintly visible BEHIND him from t=0, then flashed FULL-FRAME for ~1s at 3.0s — you see there IS a complete system but cannot parse it (t001, t003) |

Shared mechanics: negative/command verb, platform named in second 1, a NUMBER or "this" pronoun creating a contract, and **three visual regimes inside the first 4.5s** (DXo0c5bkn53: decorated title → naked accusation caption → full-frame UI; DUDyNkajSDl: takeover → arcade "RULES" card → glitch transition, three style breaks before second 7). Nothing persists >3s in a hook.

### 1.2 The withholding move (the owner-flagged "teasing") — codified

**Law: show the SHAPE of the payoff in second 0–3, censor its CONTENT.** Five independent implementations, same law:

- Blurred labels on a 5-row checklist, all toggles OFF (DX0MuRvSFV2 t001, t003)
- Blurred "Secret Settings" row text under the hero title (DXo0c5bkn53 t001)
- iOS card with blue "New" pill + green toggle, feature name pixelated (DSh8cgtjfGX t003, 3.0s)
- Glowing toggle labeled "SECRET SETTING", no location given (DM5X-WgxK27 t003, 3.0s)
- The COMPLETE answer flashed full-frame for ~1s — "show the map, deny the reading time" — followed by a flashed table of contents ("RULES: ENGAGEMENT / WATCH TIME / SKIP RATE%", on screen ~1.5s: enough to register, not enough to satisfy) that the middle section then dramatizes item-by-item (DUDyNkajSDl t003, t004)

Four sub-rules:

1. **The tease object IS the payoff object.** The t003 mystery toggle in DM5X-WgxK27 is literally the t025 (36.0s) setting; DX0MuRvSFV2's blurred checklist becomes the progress bar. Never tease with a generic graphic — plant the exact visual you'll pay off.
2. **Before/after toggle states carry the gap subliminally:** tease shows toggle ON (desired end state, DM5X t003), tutorial re-enters with it OFF (your current state, t018).
3. **Reveal window:** short reveal for names (4.5–7.5s: DSh8cgtjfGX blurred at 3.0s → "called Linking Reels" pill at 7.5s), long reveal for locations/how (23–33s: DM5X toggle planted 3.0s, paid off 36.0s). Verbal withholding mirrors it: "this new update", "this brand new feature" — the noun is a pronoun until the reveal.
4. **A metaphor can carry the loop as an ASSET SYSTEM.** "Rules to the game… win the game" (DUDyNkajSDl [3s]) opens two nested loops from one sentence, and the 8-bit arcade typography on every diagram label (RULES, 1ST, 32ND, gauges-as-score-meters) keeps the "game" promise alive for 40 seconds until "here are cheat codes" (CHEATCODES marquee, 37.5s) pays it off. One coherent visual language start to finish, not a one-off gag.

### 1.3 Loop bookkeeping (open → close registry)

Every reel runs 3–5 explicit curiosity loops and **closes all but the last**:

- DM5X-WgxK27: loop 1 (secret setting) 3.0s→36.0s; loops 2–4 (three unnamed icons in a rail, 21.0s) closed at 25.5s/37.5s/54.0s in order; loop 5 ("...because") never closed = replay.
- DXo0c5bkn53: blurred setting → Trial toggle (t011); "cheat code" → named [16s]; "double views" → receipted with 134K/134K cards (t022).
- DX0MuRvSFV2: the checklist row-by-row unblurs after each step (t008, t019, t025, t030) — **the hook graphic is the progress bar**, plus "best for last" [44s] keeps tension.
- DUDyNkajSDl: loop A "the rules" 3s→36s ("now you know the rules to the game", warm-lighting switch); loop B "how to win" 3s→37.5s ("cheat codes") → converted directly into the CTA; loop C (visual) the flashed map 3s → walked node-by-node 7.5–35s with a mid-recap zoom-out at 22.5s (t016).

**The signature ending: mid-sentence loop cut (5/6 reels).** Transcripts end on an unfinished clause that grammatically chains into the opening line: "which is why you should—" (DSh8cgtjfGX [74s], t051 — background even returns to hook-red for a color-matched loop point), "perfectly optimized because..." (DM5X [71s]), "so do this every time because" (DXo0c5bkn53), "Save this for later, and…" (DX0MuRvSFV2 t038), "since you now know—" (DUDyNkajSDl t031 — the opening title even fades back in, dimmed, as a visual bookend at the cut). No CTA, no outro, no logo. The loop IS the CTA — and in DUDyNkajSDl it's self-referential: forcing a rewatch games the watch-time rule the video itself teaches. Dau4zb1SsbG variant: ends cold on the aspirational punchline (notification, t033) with zero spoken CTA.

### 1.4 Segment architecture with typical timings

```
0–4.5s    HOOK           talking head + tease object; 2–3 visual regimes
3–10s     NEWS/PROOF     full-frame authority (official article, headline sharp/body blurred, ~3s)
                         OR fear frame ("shadow banned", DX0MuRvSFV2 [5s])
~10s      QUESTION RE-HOOK  "But why is this so good?" (Dau4zb1SsbG [10s]) — placed
                         exactly at the retention-dip point; caption chapter divider
10–25s    MECHANISM      why it works — POV dramatization or infographic
23–26s    "HERE'S THE PLAY" pivot caption (Dau4zb1SsbG t017; DSh8cgtjfGX t026 "HERE'S WHAT YOU DO")
25–55s    TUTORIAL       full-frame screen journey, face gone, 1 UI step per ~2s
~45%      MID-VIDEO RE-HOOK  (DX0MuRvSFV2 23s/56s): fear→greed switch + FRESH blurred
                         stack + receipt — re-earns the back half
55–70s    PAYOFF         receipts, counters, future-pace ("every time someone lands
                         on your page…", Dau4zb1SsbG [43–49s])
last 2s   LOOP CUT       mid-clause audio cut back to hook
```

Fear→greed ordering (loss-avoidance settings first, growth settings after the re-hook) is the repeatable skeleton of DX0MuRvSFV2. Withhold–reveal is **fractal**: every section opens its own micro-tease ("this is where the magic happens" [55s] right before the single key instruction, DSh8cgtjfGX).

**The mechanism-explainer variant (DUDyNkajSDl)** — the skeleton when the topic is "how X works" rather than "do this setting":

- Negative path (6–21.5s: publish → skipped → buried to 32ND → red "NEVER SEE IT") then positive path (21.5–35s: open → watch to end → interact → pushed to 1ST → green "ALL FOLLOWERS") in **perfect structural symmetry — the SAME assets with colors flipped red→green**. The "But" pivot between them earns a zoom-out recap of everything built so far (t016).
- Face-time budget: ~6s face hook, ~29s zero-face visualized mechanism, ~10s face CTA. The editing flex concentrates where comprehension is hardest; **the human returns exactly when trust/ask matters**.
- **Background lighting is a narrative dial:** room dimmed near-black while the diagram needs contrast (t001–t002), re-lit warm (fireplace, window) the moment the message shifts to reward/CTA (t025). A filming instruction, not a render effect.

## 2. חוקי סנכרון מילה↔ויזואל (WORD↔VISUAL SYNC RULES)

Implementable directly — our pipeline has word-level timestamps. Four sync roles, each with a signed offset from the trigger word's start:

| Sync role | Word class | Offset law | Evidence |
|---|---|---|---|
| **PLANT** (precedes) | promises, teases, "three steps" roadmaps | −2s to −23s before the naming/explanation; only teases may precede | DM5X toggle at 3.0s, explained 25.5s; Google typing starts 4.5s, "Google" spoken ~7.5s; Dau4zb1SsbG article headline leaks answer ~2s early (t004) |
| **LAND** (on the word) | nouns, names, pivots ("But", "now"), metaphor words | 0 to +500ms after word onset. Never before (preserves the reveal) | "called Linking Reels" → pill lands exactly (DSh8cgtjfGX 7.5s); "account privacy" → row spotlights (DM5X t024); "But" → whip transition on the conjunction itself (DXo0c5bkn53 t018, 25.5s) |
| **FOLLOW** (a beat after) | instructions/verbs — "hear it, then watch it done" | +300–1000ms after phrase end | "choose the most popular one" → wedge click a beat later (DM5X t034); toggle flips exactly on the verb "turn off" (DX0MuRvSFV2 t015–t016) |
| **PAYOFF** (runs past) | numbers, counters, transformations | starts +500–1000ms after the LAST word, keeps animating 3–4s into the next sentence | view counters 100K→0 / 540K→640K run ~4s past the clause (DSh8cgtjfGX t010–t013); 134K/134K labels withheld one beat until "double" (DXo0c5bkn53 t022); followers 3K→243K keeps climbing (DSh8cgtjfGX t023–t025) |

Additional laws:

- **Payoffs dock on the last word of the instruction** — phrase flies into the caption card exactly on "...first line of a caption" (DM5X t036, 52.5s).
- **List items enter one per spoken item:** "part one, part two, and part three" → P1/P2/P3 cards slide in sequentially (DSh8cgtjfGX t019–t020). Word-stacking in hooks: "NO"→"NO NO"→"NO NO NO" (Dau4zb1SsbG t001–t002).
- **What earns a visual at all:** nouns get graphics, verbs get animation, claims get receipts, metaphors get literalized ("mental screenshot" → viewfinder brackets + flash, Dau4zb1SsbG t025 AND DSh8cgtjfGX t040 — he reuses it), conjunctions get captions. Filler gets nothing.
- **Every spoken noun exists on screen within ±1.5s** (DM5X word-count discipline) and **every claim has a number, every number has a receipt** (DX0MuRvSFV2: 415K, 15,789, 8.6M, 116,098 — all screenshots).
- **One SFX per visual hit** implied: stamp slams, toggle clicks, whooshes on whips, ticker roll-ups, shutter flash, glitch transitions, type-on letters, notification slide-ins (DX0MuRvSFV2 §G; DSh8cgtjfGX §G7; DUDyNkajSDl §G8 — the mechanism section is effectively scored by UI sounds).
- **Exact-phrase callouts:** when a callout box appears, its text is the EXACT spoken phrase, landing on the syllable — "MOST INTERACTIVE" (10.5s), "NEVER SEE IT" (21s), "ALL FOLLOWERS" (34.5s), "NOW YOU KNOW" (36s) (DUDyNkajSDl §B). Never a paraphrase.
- **Verbs are animated as state transitions, never illustrated:** "bury" = rank badge 1ST→32ND across three motion-blur beats; "push it to the front" = the same animation mirrored in reverse (DUDyNkajSDl t013–t015, t022–t023).
- **Structures precede their word slightly:** the connector line starts drawing during the preceding clause so the node COMPLETES on the keyword (DUDyNkajSDl §B — pyramid finishes as "your followers" lands).
- **Native UI stands in for abstract words:** "till the end" = a full story progress bar; "I'll send it to you" = an iOS push notification arriving (DUDyNkajSDl t018, t030). Never invent a graphic when a real UI element already means the word.

**Pipeline encoding:** each planned scene gets `sync: {trigger_word_index, role: plant|land|follow|payoff, offset_ms}`. Renderer resolves against word timestamps. Default `land/+250ms`. Validation: a `land` scene must not start before its trigger word.

## 3. דקדוק האוברליי (OVERLAY GRAMMAR) — mapped to our scene catalog

### 3.1 The laws

1. **Concurrency ceiling: 1 caption + 1 graphic. Hard.** (DX0MuRvSFV2 §D; DXo0c5bkn53: when a big caption is up, nothing else is). A grouped element (3-icon rail, two twin cards) counts as one. Only sanctioned exception: a second element that is a CHILD of the first — the CHEATCODES banner persists while the template cards fan out beneath it (DUDyNkajSDl t028).
2. **Position: chest level, below the chin, face never covered** — verified across all 49 frames of DM5X. Single exception: elements placed ABOVE the head specifically so he can point up at them (medal row, DSh8cgtjfGX t039–t040). Our above-captions anchor already complies.
3. **Entrances pop on the trigger word; exits are STATE CHANGES, not out-animations** (toggle flips, label appears, card mutates — DXo0c5bkn53 §D). This matches our "NO exit animations" rule in DESIGN.md — extend it: prefer mutating the existing overlay over replacing it.
4. **Captions are not subtitles.** 1–3 words, whole sentences uncaptioned. Text is reserved for **second-person imperatives, accusations, pivots, and benefit phrases** ("YOU DIDN'T", "So do this", "BUT", "OF VIEWS FOR FREE") — **content nouns are never captioned, they are SHOWN** (Dau4zb1SsbG §F).
5. **Two caption registers:** SHOUT (caps, heavy, effects — hooks/pivots) vs whisper (lowercase, clean — step transitions, finale: "here's the play", "now"). The register switch itself signals the section change (Dau4zb1SsbG §D).
6. **Semantic color code, consistent per reel:** red = threat/wrong path (incl. background lighting, DSh8cgtjfGX t017–t018), green = validation/success, blue/cyan = the feature/action/win, gradient = brand word only, white = neutral. Set up the code in the mechanism scene, pay it off in the proof cards (DXo0c5bkn53 §F: purple=Normal, teal=Trial).
7. **Cross-scene object persistence:** objects travel from full-frame world into overlay world — ATP wedge text flies out of the site and docks into the caption card on his chest (DM5X t034→t036); "copy this over" is always physically animated.
8. **Gestures are choreographed to overlay positions** (hands frame the search bar, fingers point at the medal row — DM5X §D, DSh8cgtjfGX t039). → This is a FILMING instruction for Omer, not a render feature: reserve overlay zones before shooting.
9. **Overlays behave like physical props he is handling:** template cards fan out ON his open palm, the comment composer is framed between his two hand gestures, his hands "hold" the full diagram from below, his live face sits inside the story-ring avatar (DUDyNkajSDl t028, t029, t016, t006). The body-interaction sells 3D presence — the strongest version of law 8, requiring the overlay plan to exist before filming.
10. **Comedy lives inside the mock UI, never in the script:** poll "AM I HANDSOME? Yes 67% / Hell Yes 33%", typed reply "wanna go out?" (DUDyNkajSDl t019–t020) — jokes ride the graphics so information density never drops.

## 4. טריגרים ל־B-ROLL (full-frame takeovers)

### 4.1 What EARNS a takeover (and what doesn't)

Full-frame is earned by exactly five jobs — everything else stays an overlay on the face:

1. **Procedure the viewer must replicate** → screen journey, face leaves entirely, no PiP (DXo0c5bkn53 t004–t015: 16.5s, 8 UI steps at ~2s each).
2. **Proof of a claim** → article/receipt (DSh8cgtjfGX t004–t005: 3s, headline sharp, body blurred).
3. **Invisible mechanics ("why")** → stylized infographic on a contrasting LIGHT stage (DXo0c5bkn53 t016–t020: white-bg twin phones + donut charts).
4. **Metaphor** → the 95M-post wall with his tiny color video buried (DM5X t008–t011).
5. **Multi-screen navigation** — the sharpest rule: **one screen = overlay on him; a journey through screens = full takeover** (DM5X §E).

Counter-rules: rhetorical/emotional beats (questions, promises, pivots, punchlines) ALWAYS return to the face; never >7.5s consecutive full-frame in the dense reel (DM5X, 43% total) but up to 16.5s for tutorials; **the human never disappears >~18s** — he composites himself back into the recording (DSh8cgtjfGX t038). DUDyNkajSDl stretches the mechanism block to ~28s (61% of the reel) but only by embedding his REAL hands/phone footage inside the diagram (t010–t012, t017–t021) and his hands under the map (t016) — human presence maintained without cutting back. **Zero captions during full-frame — the UI is the text** (all reels).

**The mechanism canvas is ONE continuous vertical blueprint, not slides** (DUDyNkajSDl §E — the definitive form of trigger 3): every new node is introduced by a white connector line drawing DOWNWARD from the previous node, the camera pans/zooms over a single tall map, and because it's one canvas, the recap zoom-out on pivots comes free (full-map wides at t003 and t016). Real footage embeds INSIDE the diagram with an L-shaped connector + a live gauge pinned in a corner that TICKS between shots (61.94% → 61.54% → 07.59%) — the diagram visibly "watches" the demo, dramatizing "the algorithm measures." Subliminal-proof flash in the transition ("Seen by 40,182" inside a glitch frame, t005) — for us: own real numbers only, per the proof rule.

Inside every takeover, one engineered focal point per beat: dim-everything + glow cursor dot, black-out isolation of a single chip, selective blur so only the target menu item is legible, UI-text-replacement gags ("Post"→"Wait! ✋", DXo0c5bkn53 t006), receipt state after every action ("Created just now", "Trial Reel Posted").

## 5. מפת יישום (IMPLEMENTATION MAP)

**5.1 Hook generator**

- Current: writes a hook line + text-slam visual.
- Jatho: hook = formula (negative imperative / shock / cheat / news) + numeric contract + **tease object on screen at t=0 with censored content** + mid-hook restyle beat.
- Change: hook output schema gains `{formula, promise_count, tease_object: {scene_type, blurred_fields, payoff_scene_id}, restyle_at_ms}`. Add the 4-formula bank (§1.1) as few-shot examples. The tease object must be the SAME component the payoff uses later.

**5.2 overlay_agent/planner.py (`plan_overlays`)**

- Current: segments transcript → keyword intent (`_classify_intent`) → picks top segments by density → duration band + 0.4s gap + flavor rotation. Timing = segment window, no word-level anchoring, no cross-scene state.
- Jatho: moments picked by WORD CLASS, timed by sync role, loops tracked, captions gated.
- Changes: (a) add word-class tagging pass (noun-name / verb-instruction / claim-number / pivot-conjunction / metaphor / benefit) → each earns a scene with a `sync` block per §2; (b) **loop registry**: any scene with `blurred_fields` or a spoken open question MUST register a payoff scene; planner errors if a loop never closes and always leaves exactly one open (the ending); (c) inject `question_card` at ~10s and a re-hook beat at ~45% of duration; (d) `recallable` scenes (checklist/progress_rail) re-render with progressed state after each step instead of new scene types — this replaces flavor-rotation for list-driven scripts; (e) concurrency validator: reject plans with >1 graphic + >1 caption overlapping.

**5.3 Caption/karaoke system**
